# FigureDrawer
FigureDrawer - Утилита для отрисовки простых фигур.

<img width="805" height="460" alt="image" src="https://github.com/user-attachments/assets/58e4ecaa-72e3-498d-927c-f5c85de0ea46" />

Для работы необходимо выбрать тип фигуры. После выбора откроется окно настроек фигуры. Для отрисовки фигуры с выбранными настройками необходимо нажать кнопку "**Нарисовать фигуру**". При повторном нажатии кнопки фигура отрисовывается заново с полной очисткой пространства холста.
